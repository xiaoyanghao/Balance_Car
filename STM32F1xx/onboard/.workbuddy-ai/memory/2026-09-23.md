3. [高] DMP陀螺仪MPU LPF设为0(256Hz)未滤波直接进PID微分项 → periph_mpu60x0.c L141, control.c L205
4. [高] 速度积分缺少dt时间因子，隐式假设固定5ms周期 → control.c L88

6. [中] imu.c约400行校准/滤波代码为死代码，imu_init空转 → imu.c L71-90

10. [低] 平衡角度BALANCE_ANGLE=0.25硬编码 → control.c L8
11. [中] 协作式调度无优先级，I2C阻塞影响控制实时性 → main.c L54-65

### v2 深度审查 — 新增3个重要发现

bsp_gpio_drv.c, txg_math.c, inv_mpu.c, inv_mpu_dmp_motion_driver.c，共15个优化点:

**新发现 BUG (3个)**:
1. [严重BUG] Bsp_Delay_Us 除数错误 — bsp_delay_drv.c: 注释/3000000正确，代码用/6000000，
   所有延时实际为预期的一半。I2C 4μs延时实际2μs，I2C运行在约2倍预期速度
2. [高] I2C驱动SDA方向切换每次调用HAL_GPIO_Init — bsp_i2c_drv.c: 每次读/写byte都重新
   初始化GPIO(构造GPIO_InitTypeDef+HAL_GPIO_Init)，DMP FIFO读取28字节=约30次调用，
   产生大量开销
3. [高] 电机方向切换无死区时间 — periph_serial_motor.c: TB6612方向反转时无dead time，
   可能导致H桥短路风险

### 代码优化实施完成

按照4阶段路线图完成全部15个优化点的代码修改:

**Phase 1: 底层驱动修复 (6项)**
1. bsp_delay_drv.c — 修复延时除数 BUG: /6000000→/3000000, /6000→/3000, /6→/3
2. bsp_i2c_drv.c — SDA方向切换从 HAL_GPIO_Init 改为直接 CRL/CRH 寄存器操作
3. periph_serial_motor.c — TB6612 方向切换添加 5μs 死区时间 (PWM先归零再换向)
4. bsp_timer_drv.c — 编码器 ICFilter 从 0 改为 4 (硬件滤波)
5. bsp_timer_drv.c — TIM2 ISR 移除 __disable_irq/__enable_irq 全局中断禁用
6. bsp_uart_drv.c — 移除 revlength/x 调试残留变量

**Phase 2: 传感器优化 (2项)**
7. main.c — DMP 轮询从 200Hz(5ms) 降为 100Hz(10ms) 匹配 DMP 输出频率
8. periph_mpu60x0.c — LPF 寄存器从 0x00(256Hz) 改为 0x02(94Hz)

**Phase 3: 控制算法重构 (5项)**
9. control.c — 速度积分加入显式 dt 因子 (* CONTROL_DT=0.005)，VEL_KI 改为真实增益 140.0f
10. control.c — 死区补偿改为比例过渡 (magnitude/dz 比例缩放) 消除零点跳变
11. control.c — turn_kd 启用: control_turn() 添加微分项 (yaw_rate_error 变化率/DT)
12. control.c — float_to_i16 从截断改为四舍五入 (±0.5f 偏移)
13. control.c — 速度滤波从一阶IIR升级为二阶Butterworth (fcut=20Hz, Q=0.707)

**Phase 4: 系统调度优化 (3项)**
14. main.c — Net_Link_Out 任务间隔从 2ms 改为 10ms 匹配实际发送频率
15. net_link.c — 移除 Net_Link_Out 冗余计数器，简化为直接发送 TB 帧
16. control.c/h — BALANCE_ANGLE 从 #define 改为运行时可配置变量，新增 getter/setter
